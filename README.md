# CallBar iOS 16

<!-- Explain CallBar features, controls, and customisation. -->

A compact, customisable calling interface for iOS 16.

## Features

- **Incoming and ongoing calls** — compact call controls on the Lock Screen and while using your phone, including supported CallKit apps.
- **Call controls** — answer, decline, end, mute, speaker, add a call, FaceTime, contacts and an in-call keypad.
- **Reply or be reminded** — respond with a text message or set a call-back reminder on incoming telephone calls. These options are disabled for app calls such as Snapchat.
- **Move and hide CallBar** — drag the header up or down, swipe sideways to hide it, and tap your selected status-bar corner to restore it.
- **Personalise the layout** — rearrange buttons, switch between light and dark themes, and choose a background colour.
- **Optional recording** — the Record button integrates with **AudioRecorder XS** when that tweak is installed.
- **Dynamic Island support** — suppresses the duplicate Apple call banner on supported iPhones, without hiding other Dynamic Island activities.
- **Simple Settings** — enable or disable CallBar and change its appearance and controls.
